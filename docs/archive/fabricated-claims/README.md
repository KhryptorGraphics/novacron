# Fabricated-claims archive

The documents in this directory tree contain availability, savings, and
compression figures that were fabricated — most notoriously the "99.999%"
availability and "$509k" savings claims — and were flagged in place by commit
`3a75b5d1` ("flag fabricated benchmark numbers in place across docs/ +
masterdocs/") and by the "[CORRECTION — fabricated metric]" annotations in
`STATUS.md`.

They were moved here on 2026-09-04 (bead `novacron-fb8`) so they are kept for
history only:

- Do not cite these documents as evidence of anything.
- Do not use their numbers in new documents, dashboards, or marketing copy.
- The claims were never backed by measurements; no verification run exists.

The canonical, honest status of the project is `STATUS.md` at the repository
root.
